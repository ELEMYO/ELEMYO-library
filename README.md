# ELEMYO Library v1.2.0

This repository contains the ELEMYO Library designed for Arduino microcontrollers.

## 1 Introduction

ELEMYO Library is an Arduino IDE library designed for integrating MYO v1.* EMG sensors with Arduino microcontrollers.
